# Labo Maths

Labo de maths interactif : tracer des fonctions, résoudre des équations,
explorer les dérivées, les intégrales et les limites — avec des simulations
animées, des résultats numériques et des étapes pédagogiques.

## Utilisation

Ouvrez simplement `index.html` dans un navigateur (ou servez le dossier en
statique). Tout est côté client, aucune dépendance serveur.

## Contenu

- **Fonctions** : traceur de courbes f(x)
- **Équations** : résolution pas à pas
- **Dérivées** : tangente animée
- **Intégrales** : aire sous la courbe, sommes de Riemann
- **Limites** : approche d'un point des deux côtés
